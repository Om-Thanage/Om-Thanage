### 3pm - npm Trust Layer

[![GitHub](https://img.shields.io/badge/GitHub-3pm-181717?style=flat-square&logo=github)](https://github.com/Unchanted/3pm)
![Solidity](https://img.shields.io/badge/Solidity-363636?style=flat-square&logo=solidity&logoColor=white)
![Base](https://img.shields.io/badge/Base-0052FF?style=flat-square&logo=coinbase&logoColor=white)
![Hardhat](https://img.shields.io/badge/Hardhat-FFF100?style=flat-square&logo=hardhat&logoColor=black)
![Fastify](https://img.shields.io/badge/Fastify-000000?style=flat-square&logo=fastify&logoColor=white)
![Next.js](https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=next.js&logoColor=white)
![Ollama](https://img.shields.io/badge/Ollama-000000?style=flat-square&logo=ollama&logoColor=white)

**M-of-N multisig release authorization for npm packages**, built so one stolen token or one rogue maintainer can't ship malware downstream. Co-signers approve the exact tarball hash with **EIP-712 signatures**, and the release is recorded on-chain on **Base**. On the consumer side, `3pm install` checks the downloaded bytes against the on-chain hash, flags typosquats, and runs heuristics plus a **local Gemma 3** diff summary before anything installs. Includes a CLI, backend, web app, PWA and browser extension.
